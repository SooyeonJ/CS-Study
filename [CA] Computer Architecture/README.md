실행시간 = (명령어 수 × CPI) × (1 / 클럭속도)

CPI (평균 실행 클록 수) : 한 명령어를 실행하는 데 필요한 평균 클록 사이클 수
Ex. CPI = 1 # 명령어 1개당 클록 1번 사용 (값이 작을수록 성능 좋음)

클럭속도 (Clock Rate) : 1초에 발생하는 클록 횟수 (Hz)
Ex. 2GHz : 초당 20억 번 클록 발생

클럭속도(클록 주파수) = 1 / 클록주기

총 클록 사이클 = 명령어 수 × CPI
실행시간 = 총 클록 사이클 × 클록주기 = (명령어 수 × CPI) × (1 / 클럭속도)
