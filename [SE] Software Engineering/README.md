# Software Engineering

## 오답노트
#### 계획 -> 분석 -> 설계 -> 구현 -> 테스트 -> 유지보수
### SDLC
- 나선형 모델 : 비선형적, 반복적 개발 / 개발 단계 - 프로토타입 만듦
- 컴포넌트 기반 모델 (Component-Based Development, CBD)
- : 이미 만들어진 재사용 가능한 컴포넌트(Component)를 조립하여 소프트웨어를 개발하는 방식
- : SDLC(요구사항 → 설계 → 구현 → 테스트) 안에서
- 구현/설계 단계에서 컴포넌트 재사용 방식으로 개발하는 모델
- 기존 컴포넌트 재사용 → 개발량 감소 가능 (맞음)
- 생산성 ↑ / 개발기간 ↓ / 유지보수 용이
- XP 모델 (Extreme Programming)
- : 1990년대 후반 등장한 애자일(Agile) 개발 방법론
- RAD 모댈 => CASE 도구를 활용하여 빠른 개발 지원

### 계획
- FP = “코드가 아니라 기능으로 소프트웨어 크기 측정 (기술/구현 무관)”

### 분석
- 요구사항명세서(SRS)
- : 기능적/비기능적 요구사항 및 검증(테스트) 기준
- 구조적 분석 작업 순서
- 배경도 작성 -> 상.하위 흐름도 작성 -> 자료 사전 작성 -> 소단위 명세서 작성
- (구조적방법론) 데이터흐름 다이어그램 / (객체지향) 유스케이스 다이어그램
